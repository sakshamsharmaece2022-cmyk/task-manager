# Task Manager App

A full-stack Task Manager application where users can manage tasks across three stages: Todo, In Progress, and Done.

## Live Demo
- Frontend: https://mellow-zuccutto-62688d.netlify.app
- Backend: https://task-manager-6b72.onrender.com

## Features
- User Registration and Login (JWT Authentication)
- Create, Update and Delete tasks
- Three task stages: Todo, In Progress, Done
- Clean and responsive UI

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Authentication: JWT + bcrypt

## Deployment
- Frontend: Netlify
- Backend: Render

## Assumptions & Decisions
- Used localStorage for token storage
- Backend is mandatory as AI tools were used
- Free tier used for all cloud services
